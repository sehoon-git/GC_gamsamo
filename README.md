# 우리동네 상담사

> **게임 안에, 모두를 담다 — 서로 다른 이야기가 머물 수 있는 상담실**

**제작: GC_gamsamo | 장르: AI 대화형 상담 시뮬레이션 | 플랫폼: Windows 64비트**

## 1. 게임 소개

《우리동네 상담사》에서 플레이어는 작은 동네 상담실의 상담사가 됩니다. 문을 열고 들어오는 다섯 사람은 저마다 다른 고민을 품고 있습니다. 취업의 좌절, 지역과 직장 사이의 선택, 주변의 기대, 달라진 가족 관계, 문화적 배경과 소속감까지. 플레이어는 이들의 이야기를 듣고 자신의 말로 답하며 상담을 이어갑니다.

상대의 말을 더 듣고 싶다면 질문하고, 마음이 이해된다면 공감하며, 함께 생각해 볼 방법이 있다면 제안할 수 있습니다. AI 내담자는 자신의 성격과 상황, 앞서 나눈 이야기를 바탕으로 반응합니다. 상담이 끝나면 대화와 평가를 돌아보고, 다시 만날 때는 그 이야기를 이어갑니다.

우리가 담고 싶은 경험은 **각자의 삶을 이해하고, 스스로 선택할 수 있도록 곁을 내어 주는 것**입니다. 상담을 통해 새로운 사람을 만나고, 얻은 보상으로 상담실을 꾸미며 나만의 공간을 만들어 갑니다.

## 2. 게임 특징과 해커톤 주제

### 내 말로 이어가는 상담

답변을 직접 입력하므로 플레이어마다 대화의 흐름이 달라집니다. 질문·공감·제안을 자유롭게 섞어 사용할 수 있고, 질문 횟수 제한 없이 상대의 이야기를 탐색할 수 있습니다. 내담자가 먼저 꺼낸 한마디에서 시작해 그 사람의 감정과 사정을 조금씩 알아가는 과정이 핵심 플레이입니다.

### 서로 다른 다섯 사람의 시선

해커톤 주제 **「게임 안에, 모두를 담다」**를 서로 다른 삶을 듣는 경험으로 풀었습니다. 특히 **‘다른 시선 플레이하기’**를 중심에 두고, **‘고정관념과 장벽 깨기’**, **‘현실을 게임으로 풀기’**를 인물과 상담 방식에 담았습니다.

| 내담자 | 만나게 될 이야기 | 함께 생각할 질문 |
| --- | --- | --- |
| 서윤 | 취업 실패로 흔들리는 자기 가치 | 결과에 지친 사람의 현실과 마음을 어떻게 함께 살필까? |
| 도현 | 이직과 잔류 사이의 고민 | 일하는 지역, 급여, 관계, 생활 조건 중 나에게 중요한 것은 무엇일까? |
| 태준 | 주변의 기대와 비판 속 자기 판단 | 정당한 비판과 지역에 대한 편견을 어떻게 구분할까? |
| 연우 | 이혼 이후 아이와 맺는 관계 | 아이의 기쁨과 부모 자신의 슬픔을 함께 존중할 수 있을까? |
| 하린 | 다문화가정의 소속감, 가족에 대한 애정과 부담 | 자신의 배경을 드러내는 범위와 역할은 누가 정해야 할까? |

게임은 취업 여부, 사는 지역, 가족 형태, 문화적 배경으로 사람을 단정하지 않고 **그 사람의 생활 조건과 선택을 이해하는 태도**에 주목합니다.

하린의 경우 학교에서 다문화가정 학생을 대표하는 발표를 제안받습니다. 상담에서는 가족에 대한 애정과 부담을 함께 듣고, 하린이 자신을 어디까지 드러낼지 생각하도록 돕습니다. 발표에 참여하거나, 참여하지 않거나, 공개 범위를 조정하는 선택 모두 가능하며 **본인의 선택과 속도를 존중하는 과정**이 평가에 반영됩니다.

### 대화를 돌아보고 다시 만나는 경험

상담은 **내담자의 변화**와 **상담자의 대응**이라는 두 축으로 평가합니다. 플레이어의 대응에서는 공감과 경청, 단정하지 않는 탐색, 선택과 속도의 존중, 현실적인 맥락의 이해를 살핍니다. 취업·이직·재결합·발표 참여와 같은 특정 결말을 필수 정답으로 두지 않습니다.

기록부에는 상담 원문과 평가 근거가 남습니다. 플레이어는 자신이 어떤 말을 건넸는지 되짚고, 다음 상담에서 다른 질문과 접근을 시도할 수 있습니다. 구직, 가족 돌봄, 지역과 소속감 같은 일상의 문제를 **대화 → 성찰 → 재방문**의 게임 경험으로 연결했습니다.

### 자신의 속도로 읽고, 상담실을 꾸미기

대사는 텍스트로 읽고 답변은 직접 작성합니다. 타이핑을 즉시 표시하는 `바로 보기`, 대화 기록 다시 읽기, 마우스 전송 버튼과 키보드 단축키를 제공해 읽기와 조작 방식을 선택할 수 있습니다.

새 게임은 **200C**로 시작합니다. 상담 보상으로 창문·문·서류철·PC·PC 배경·벽지의 **6개 분류, 48종 치장**을 구매하고 장착할 수 있습니다. PC에서는 상점, 프로필, 사진첩, 환경설정을 이용하며, 다섯 내담자를 모두 클리어하면 최종 엔딩이 해금됩니다.

## 3. 실행 방법

**준비물:** Windows 64비트 PC, 마우스·키보드, 인터넷 연결, 팀에서 제공하는 AI 접속 설정 파일.

1. 제출 ZIP을 원하는 폴더에 **모두 압축 해제**합니다.
2. 아래 안내에 따라 AI 접속 설정 파일을 준비합니다.
3. 실행 빌드 폴더에서 **`우리동네상담사.exe`**를 실행합니다.
4. 시작 화면에서 **새 게임**을 선택합니다. 저장된 게임은 **불러오기**로 이어갈 수 있습니다.

실행 파일과 함께 제공되는 `우리동네상담사_Data` 폴더, `UnityPlayer.dll` 등은 같은 위치에 유지해 주세요. 게임 실행에는 Unity Editor나 로컬 AI 모델 설치가 필요하지 않습니다.

### AI 접속 설정

팀에서 제공한 `ai-connection.json`을 다음 위치에 넣습니다. 폴더가 없으면 생성합니다.

```text
%USERPROFILE%\AppData\LocalLow\DefaultCompany\GC_gamsamo\ai-connection.json
```

이 파일에 담긴 서버 주소와 접근 키로 AI 서버에 연결합니다. 새로운 상담과 평가를 진행하려면 인터넷과 AI 서버 연결이 필요합니다. 연결 오류가 표시되면 설정 파일 위치와 서버 연결 상태를 확인한 뒤 화면의 `재시도`를 눌러 주세요.

<details>
<summary>프로젝트 원본으로 실행하기</summary>

1. Unity Hub에서 **Unity 6000.3.28f1**을 설치합니다.
2. `Assets`, `Packages`, `ProjectSettings` 폴더가 있는 프로젝트 루트를 엽니다.
3. `Gamsamo > AI > Import Connection JSON`에서 전달받은 AI 접속 설정 파일을 가져옵니다.
4. `Assets/_Project/Scenes/StartMenu.unity`를 열고 **Play → 새 게임**으로 시작합니다.

## 4. 플레이 방법

**문 열기 → 이야기 듣기 → 답변 작성 → 상담 종료·평가 → 내보내기 → 다음 만남**

1. **내담자 맞이하기:** 상담실 왼쪽 문을 클릭합니다. 내담자가 들어와 먼저 자신의 이야기를 꺼냅니다.
2. **대화 이어가기:** 입력창에 질문이나 답변을 쓰고 `전송` 또는 `Ctrl + Enter`를 누릅니다. 상대의 말에서 궁금한 점을 묻거나, 느꼈을 감정을 짚으며 대화를 이어갑니다.
3. **기록 살펴보기:** `대화 기록` 버튼이나 책상 위 서류철을 열어 상담 메모·대화 원문·상담 결과를 확인합니다.
4. **상담 마치기:** `상담 그만하기`를 누르고 확인합니다. 대화 저장과 평가가 끝날 때까지 기다립니다.
5. **결과 확인하기:** **내담자 변화와 상담자 대응이 각각 70점 이상**이면 해당 내담자를 클리어합니다. 미달하면 같은 내담자와 재상담할 수 있습니다.
6. **다음 만남 준비하기:** `환자 내보내기`를 누른 뒤 다시 문을 클릭합니다. 클리어했다면 다음 내담자를, 아직 클리어하지 못했다면 같은 내담자를 만납니다.

진행 순서는 **서윤 → 도현 → 태준 → 연우 → 하린**입니다. 게임은 진행과 상담 내용을 자동으로 저장하며, 시작 화면의 `불러오기`로 이어할 수 있습니다. 저장된 진행이 없으면 불러오기는 비활성화됩니다.

| 조작 | 기능 |
| --- | --- |
| 마우스 왼쪽 클릭 | 문·PC·서류철·안내서·버튼 조작 |
| 키보드 입력 | 상담 답변 작성 |
| `Enter` | 입력창에서 줄바꿈 |
| `Ctrl + Enter` / `전송` | 답변 전송 |
| `바로 보기` | 타이핑 중인 대사를 즉시 표시 |
| 대화칸 스크롤 | 긴 대화 내용 읽기 |
| 기록부·안내서의 이전/다음 버튼 | 문서 페이지 이동 |
| `Esc` | 지원되는 창 닫기, 설정의 미적용 변경 취소 |

화면 크기와 화면 모드, 전체·배경음·효과음 음량은 시작 화면이나 PC의 **환경설정**에서 조절하고 `적용`으로 저장합니다.

## 5. AI 활용

### 플레이에 사용한 AI

AI는 **서로 다른 인물과 자유롭게 대화하는 경험**을 담당합니다. Qwen 계열 언어 모델을 외부 추론 서버에서 실행하고, 다음 기능에 활용했습니다.

- **내담자 대화:** 인물의 설정·성격·공개 가능한 정보와 플레이어의 발언을 바탕으로 응답합니다.
- **대화 기억:** 앞서 나눈 상담을 반영해 같은 인물과 이야기를 이어갈 수 있도록 합니다.
- **상담 평가:** 대화 원문을 근거로 내담자의 변화와 플레이어의 대응을 평가합니다.

인물별 대화 규칙에는 고정관념을 피하고 선택을 존중하는 기준을 담았습니다. 설정에 없는 성별·국적·가족 이력을 임의로 추가하지 않도록 하고, 강요에 대한 동의를 충분한 변화로 평가하지 않도록 설계했습니다. 이렇게 **다양성과 포용의 가치를 인물 소개와 AI 반응·평가에 함께 연결**했습니다.

AI 서버는 FastAPI·LangGraph·vLLM으로 구성했습니다. 게임 진행, 정보 공개 확정, 보상 지급, 구매와 저장은 Unity의 게임 규칙에 따라 처리합니다.

### 제작에 사용한 AI

| 활용 분야 | 도구 및 활용 내용 |
| --- | --- |
| UI 이미지 | **ImageGen**으로 대화 패널·종이 버튼을 만들고 기록부 이미지의 배경과 사진 영역을 편집했습니다. |
| 배경음 | **ACE-Step 1.5 Turbo**로 곡을 생성했습니다. 상담실 곡은 **Basic Pitch**로 음표를 추출한 뒤 피아노와 합성 악기로 재연주했고, 엔딩 곡은 선택한 생성 음원을 편집했습니다. |
| 효과음 | CC0 Foley 자료를 바탕으로 한 **Gaussian/PCA 모델과 음향 합성**으로 효과음을 제작했습니다. |
| 음원 검토 | **Voxtral·YAMNet**을 음원 후보의 자동 검토에 활용했습니다. |
| 개발 보조 | **Codex**로 코드와 문서 작성, UI 수정, 오류 분석을 보조했습니다. |

### AI에 전달한 프롬프트 예시

아래는 개발 과정에서 팀이 AI에 전달한 실제 요청을 의미를 유지하며 요약한 예시입니다. 인물의 배경과 원하는 경험을 설명하고, 직접 플레이하며 발견한 문제를 구체적으로 전달하는 방식으로 활용했습니다. 각 예시는 당시의 설계·개선 요청이며, 현재 기능과 실행 방법은 위 안내를 기준으로 합니다.

**1. 캐릭터 스토리와 대화 시스템 설계**

> 서윤은 대학 졸업 후 3년째 취업을 준비하며 카페에서 일합니다. 반복된 실패로 자신의 가치를 낮게 평가하고, 떨어진 회사에 합격한 친구를 질투하는 마음까지 부끄러워합니다. 카페에서는 신입 교육을 맡을 만큼 일을 잘하지만 이를 능력으로 인정하지 않습니다. 취업의 현실적인 부담을 함께 살피면서, 자신의 마음을 표현하고 지원과 휴식의 시기를 스스로 정하는 인물로 만들고 싶습니다. 이 이야기를 바탕으로 서버에 맞는 로컬 LLM과 vLLM, 프레임워크, 대화 기억·컨텍스트 관리 방식을 논의해 주세요. 아직 결정하지 않은 부분은 임의로 정하지 말고 질문해 주세요.

인물의 겉으로 드러나는 고민, 말하기 어려운 감정, 강점과 변화의 방향을 함께 전달하고, 이를 유지할 대화 구조를 AI와 검토했습니다.

**2. 직접 대화한 뒤 응답 품질과 플레이 흐름 검토**

> “부모님에서 보내는 채용 정보”는 조사가 어색하고, “말씀드릴 수 있는 게 아무것도 없네요”는 맥락상 무엇을 뜻하는지 이해하기 어렵습니다. 모델의 추론 능력 때문인지 대화 설계 때문인지 분석해 주세요. 초기 방식처럼 주요 질문을 다섯 개로 한정하면 한 주제가 길어지고 다음 질문을 떠올리기 어렵습니다. 상담 경험이 없는 플레이어도 대화를 이어갈 수 있도록 어떻게 조정하면 좋을지 제안해 주세요. 우선 코드는 수정하지 말고 의견만 주세요.

실제 응답 문장과 플레이 중 느낀 어려움을 근거로 언어의 자연스러움과 대화 진행 방식을 검토하도록 요청했습니다.

**3. 서버 검증과 다른 네트워크의 Unity 연결 점검**

> 최신 변경을 가져와 서버에서 검증하고, 문제가 없으면 다른 환경의 Unity에서도 실행한 뒤 LLM 응답을 받을 수 있도록 준비해 주세요. 서로 다른 네트워크를 연결하는 기능이 없다면 진행을 멈추고 알려 주세요.

개발 보조 AI에 검증 순서와 중단 조건을 명시해, 서버와 게임 클라이언트의 연결을 단계적으로 점검하도록 요청했습니다.

**4. 상담실 이미지와 분위기 구체화**

> 상담실 중앙에는 화면을 가로지르는 긴 테이블을 배치하고, 문은 3분의 2만 보이게 해 주세요. 시간대 대신 상담받는 사람의 주차별 기분에 따라 맑음·흐림·비로 분위기를 표현하고 싶습니다. 문·책상·배경은 병원에 어울리는 색상으로 맞추고, 오른쪽 아래 물체는 노트로 표현해 주세요.

오브젝트의 위치·노출 비율·색상과 감정에 따른 분위기를 구체적인 시각 요구로 전달했습니다.

**5. 치장품 상점 UI 구성**

> 분리해 둔 창문·문·서류철·PC 치장품 에셋을 분류별 탭으로 나눠 주세요. 기존 구매·판매 버튼이 있던 자리에는 현재 보유 금액을 보여 주는 창을 배치해 주세요.

판매할 치장품의 분류와 화면 요소의 역할을 설명해, 상품 탐색과 잔액 확인이 쉬운 상점 구성을 요청했습니다.
