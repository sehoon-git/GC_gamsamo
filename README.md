# 우리동네 상담사

**GC_gamsamo · 2026 게임인재원 AI 해커톤**

> **게임 안에, 모두를 담다 — 서로 다른 삶의 이야기에 귀 기울이는 우리 동네 상담실**

《우리동네 상담사》는 동네 상담실을 찾아온 사람들의 이야기를 듣고, 직접 입력한 말로 대화를 이어가는 **AI 대화형 상담 시뮬레이션 게임**입니다. 취업, 일과 지역, 이혼 이후 가족 관계, 다문화가정의 소속감처럼 서로 다른 현실을 가진 내담자들을 만납니다.

플레이어는 질문·공감·제안을 자유롭게 건네며 각자의 감정과 생활 조건을 이해하고, 내담자가 자신의 기준으로 선택할 수 있도록 대화합니다. AI는 인물의 설정과 앞선 대화에 따라 반응하고, 상담 결과는 **공감과 경청, 단정하지 않는 탐색, 선택과 속도의 존중**을 함께 살핍니다. 한 사람의 이야기를 이해하는 과정이 다음 만남과 상담실의 성장으로 이어집니다.

## 해커톤 주제와 기획 의도

이번 해커톤의 **「게임 안에, 모두를 담다」**를, 서로 다른 삶의 맥락을 듣고 관점을 넓히는 플레이로 풀었습니다. 세부 주제 **③ 다른 시선 플레이하기**를 중심으로, **① 고정관념과 장벽 깨기**와 **④ 현실을 게임으로 풀기**를 인물 설정·대화·평가 규칙에 연결했습니다.

| 주제 | 게임에 담은 방식 |
| --- | --- |
| 다른 시선 플레이하기 | 내담자마다 다른 경험·감정·생활 조건을 대화로 알아갑니다. 같은 인물과 재상담하며 이전 이야기를 이어 듣고, 자신의 첫 판단을 다시 생각할 기회를 만듭니다. |
| 고정관념과 장벽 깨기 | 취업 여부, 사는 지역, 가족 형태, 문화적 배경으로 사람의 가치를 단정하지 않도록 인물별 경계를 설계했습니다. 이직·잔류, 발표 참여·불참 등 각자의 선택을 존중하는 대화를 평가합니다. |
| 현실을 게임으로 풀기 | 구직의 부담, 일과 생활의 균형, 가족 돌봄과 소속감 같은 일상의 고민을 상담·기록·재방문으로 경험합니다. 공감과 이해를 두 축의 평가 및 다음 만남으로 이어지는 게임 흐름에 담았습니다. |

플레이의 문을 넓히기 위해 **텍스트 중심 대화, 마우스 전송과 키보드 단축키, 질문 횟수 제한 없는 진행, 타이핑 즉시 표시, 기록 다시 읽기**를 제공합니다. 읽고 생각한 뒤 자신의 말로 답할 수 있도록 구성했습니다. 이는 현재 제공하는 읽기·조작 선택에 대한 설명이며, 화면 읽기 프로그램·음성 입력·다국어 지원은 구현 범위에 포함하지 않습니다.

예를 들어 하린은 학교에서 다문화가정 학생을 대표하는 발표를 제안받습니다. 상담에서는 가족에 대한 애정과 부담을 함께 듣고, **어디까지 자신을 드러내고 어떤 역할을 맡을지 본인이 정할 수 있도록** 돕습니다. 발표 참여·불참·범위 조정 모두 가능한 선택으로 두었으며, 이 자율성은 캐릭터 설정과 평가 기준에 함께 반영되어 있습니다.

## 1. 실행 방법

### 제출된 게임 실행

1. 제출 ZIP을 **모두 압축 해제**합니다.
2. 아래 「AI 서버 연결 설정」에 따라 전달받은 접속 설정을 준비합니다.
3. 실행 빌드 폴더의 **`우리동네상담사.exe`**를 실행합니다. 같은 폴더의 `우리동네상담사_Data`, `UnityPlayer.dll` 등 동봉 파일을 함께 유지해야 합니다.
4. 시작 화면에서 **새 게임**을 선택합니다. 저장된 진행이 있으면 **불러오기**로 이어갈 수 있습니다.
5. 상담실 왼쪽 문을 클릭해 첫 내담자를 맞이합니다.

게임 실행만 할 때는 Unity Editor나 로컬 AI 모델을 설치하지 않아도 됩니다. AI 추론은 외부 서버에서 처리하므로, 서버와 연결되지 않으면 새로운 상담과 평가를 진행할 수 없습니다.

### AI 서버 연결 설정

제출 담당자가 제공한 `ai-connection.json`을 사용합니다. 이 파일에는 `api_url`과 `api_key`가 필요하며, 외부 서버는 HTTPS로 연결합니다. 실제 주소와 접근 키는 README나 공개 저장소에 기재하지 않습니다.

현재 프로젝트 설정(`DefaultCompany / GC_gamsamo`)의 Windows 기본 위치는 다음과 같습니다. 폴더가 없으면 생성한 뒤 설정 파일을 넣습니다.

```text
%USERPROFILE%\AppData\LocalLow\DefaultCompany\GC_gamsamo\ai-connection.json
```

다른 위치에 설정 파일을 두려면 Windows PowerShell에서 아래와 같이 실행할 수 있습니다. 먼저 `우리동네상담사.exe`가 있는 폴더로 이동하고, 전달받은 설정 파일을 같은 폴더에 놓습니다.

```powershell
$env:GAMSAMO_AI_CONNECTION = (Resolve-Path ".\ai-connection.json").Path
Start-Process ".\우리동네상담사.exe"
```

환경변수를 지정하지 않은 상태에서 설정 파일을 실행 파일 옆에 놓는 것만으로는 자동 적용되지 않습니다. 회사명·제품명을 바꿔 빌드했다면 저장 위치도 달라지므로 위 환경변수 방식으로 파일을 지정할 수 있습니다.

### Unity 프로젝트 원본 실행

1. Unity Hub에서 **Unity 6000.3.28f1**을 설치합니다.
2. `Assets`, `Packages`, `ProjectSettings`가 있는 프로젝트 루트를 추가하고 엽니다.
3. 패키지 복원과 에셋 임포트가 끝나면 `Gamsamo > AI > Import Connection JSON`으로 전달받은 접속 설정을 가져옵니다.
4. `Assets/_Project/Scenes/StartMenu.unity`를 열고 **Play → 새 게임**으로 시작합니다.
5. Windows 빌드 시 `StartMenu` → `ConsultationRoom` 순서로 씬을 포함하고, 실행 파일명을 `우리동네상담사.exe`로 지정합니다. 일반 플레이용 빌드는 Development Build를 끈 상태로 만듭니다.

AI 서버를 직접 구성하는 개발자는 [AI 실행 안내](ai/README.md), [서버 환경 설정](ai/environment.md), [API 계약](contracts/README.md)을 참고하세요. 모델 가중치와 추론 서버는 게임 실행 빌드에 포함하지 않습니다.

## 2. 플레이 방법

상담의 핵심은 **상대가 어떤 상황에서 어떤 마음을 느끼는지 묻고, 본인의 선택과 속도를 존중하는 것**입니다. 평가에서는 내담자의 변화와 함께 플레이어의 공감·경청·탐색·현실 맥락 이해를 살핍니다.

1. **입장:** 상담실 왼쪽 문을 클릭하면 현재 진행에 해당하는 내담자가 들어와 먼저 이야기합니다.
2. **대화:** 입력창에 답변을 작성하고 `전송` 또는 `Ctrl + Enter`를 누릅니다. 질문 수나 대화 횟수 제한 없이 이야기를 이어갈 수 있습니다.
3. **기록 확인:** 대화 기록 버튼 또는 책상 위 서류철에서 상담 메모·대화 원문·상담 결과를 확인합니다.
4. **상담 종료:** 원하는 시점에 `상담 그만하기`를 누르고 확인합니다. 응답 처리와 원문 저장 이후 평가가 진행됩니다.
5. **다음 만남:** 평가와 저장이 끝나면 `환자 내보내기`를 누릅니다. **내담자 변화와 상담자 대응이 각각 70점 이상**이면 다음 내담자로 진행하고, 미달이면 같은 내담자를 다시 만나 상담을 이어갑니다.
6. **꾸미기와 엔딩:** 상담 보상으로 PC의 상점에서 치장을 구매·장착합니다. 다섯 내담자를 모두 클리어하면 최종 엔딩이 해금됩니다.

정식 진행 순서는 **서윤 → 도현 → 태준 → 연우 → 하린**입니다.

| 내담자 | 이야기의 중심 | 함께 생각할 관점 |
| --- | --- | --- |
| 서윤 | 취업 실패와 자기 가치 | 구직의 현실과 부담을 살피며 자신의 가치를 돌아보기 |
| 도현 | 이직과 잔류 사이의 고민 | 지역·급여·관계·생활 조건을 함께 고려해 자기 기준 찾기 |
| 태준 | 주변의 기대와 비판 | 정당한 비판과 지역 편견을 구분하고 자신의 판단 세우기 |
| 연우 | 이혼 이후 아이와의 관계 | 아이의 기쁨과 자신의 슬픔을 함께 이해하고 각자의 감정 존중하기 |
| 하린 | 다문화가정의 소속감과 가족에 대한 애정·부담 | 정체성 공개와 대표 역할의 범위를 스스로 선택하기 |

### 조작 안내

| 조작 | 기능 |
| --- | --- |
| 마우스 왼쪽 클릭 | 문·PC·서류철·안내서·버튼 조작 |
| 키보드 입력 | 상담 답변 작성 |
| `Enter` | 입력창 줄바꿈 |
| `Ctrl + Enter` / `전송` | 작성한 답변 전송; 한글 조합 중에는 전송하지 않음 |
| `바로 보기` | 타이핑 중인 대사를 즉시 표시 |
| 대화칸 스크롤 | 기존의 긴 대화 내용 열람 |
| `Esc` / 바깥 영역 클릭 | 해당 기능이 지원하는 창 닫기; 설정의 미적용 변경은 취소 |
| 기록부·안내서의 이전/다음 버튼 | 문서 페이지 이동 |

현재 대화창은 한 응답을 한 칸에서 읽는 방식이며 대화 자체의 쪽 이동은 사용하지 않습니다. 응답 대기 중에는 안내 문장 뒤의 점이 1→2→3개로 반복됩니다.

## 3. 주요 기능

- **자유 입력 AI 상담:** 자신의 말로 질문하고 공감할 수 있습니다. 내담자별 설정과 이전 대화를 바탕으로 첫 발화·답변·재방문 대화를 생성해 각자의 이야기를 이어갑니다.
- **상담 기록과 평가:** 상담 원문, 공개된 정보, 두 축의 평가 점수와 근거를 기록부에서 확인합니다. 대화를 되짚으며 상대의 입장과 자신의 대응을 돌아볼 수 있습니다.
- **진행과 자동 저장:** 새 게임·이어하기·재상담을 지원하며 상담 초안과 진행을 저장합니다. 새 게임은 별도 진행으로 시작하고 이전 진행의 원문을 섞지 않습니다.
- **보상과 상담실 꾸미기:** 새 게임은 **200C**로 시작합니다. 창문·문·서류철·PC·PC 배경·벽지의 6분류, 총 48종 치장을 미리 보고 구매·장착할 수 있습니다. 기존 저장을 불러올 때 초기 자금을 다시 지급하지 않습니다.
- **PC와 안내서:** 프로필, 사진첩, 상점, 환경설정 및 게임 안내서를 제공합니다.
- **화면·소리 설정:** 1280×720 / 1920×1080 해상도, 화면 모드, 전체·BGM·효과음 음량을 설정합니다. `적용`을 누르면 저장됩니다.
- **후일담과 엔딩 흐름:** 개별 클리어 이후 후일담과 다섯 명 클리어 이후 최종 엔딩으로 연결됩니다. 현재 콘텐츠 준비 상태는 아래 제한 사항을 참고하세요.

시작 화면으로 돌아가면 화면에 표시된 서류 내용을 비웁니다. 저장 파일은 보존되며, `불러오기`를 선택하면 해당 진행의 상담 기록을 다시 복원합니다.

## 4. AI 활용 내역

| 활용 영역 | 사용 기술과 적용 내용 |
| --- | --- |
| 게임 내 대화·평가 | Qwen 계열 언어 모델과 FastAPI·LangGraph·vLLM 기반 서버로 내담자 응답, 대화 기억, 상담 종료 후 평가를 처리합니다. 인물별 고정 설정·정보 공개 조건·앞선 대화를 반영하고, 공감·경청·자율성 존중을 평가 기준에 연결합니다. |
| 이미지 제작 | ImageGen으로 대화 패널·종이 버튼 등 UI 이미지를 제작하고, 기록부 이미지의 배경·사진 영역을 편집했습니다. |
| 배경음 제작 | ACE-Step 1.5 Turbo로 BGM 후보를 생성했습니다. 상담실 곡은 Basic Pitch로 음표를 추출한 뒤 FreePats 피아노와 합성 악기로 재연주했고, 엔딩 곡은 선택한 생성 음원을 편집·마스터링했습니다. |
| 효과음 제작·검토 | CC0 Foley 자료를 이용한 로컬 Gaussian/PCA 모델과 합성으로 효과음을 제작했습니다. Voxtral·YAMNet은 음원 후보의 자동 검토에 활용했습니다. |
| 개발 보조 | Codex를 활용해 코드·문서 작성, UI 수정, 오류 분석 및 회귀 검증 작업을 보조했습니다. |

대화 모델의 최근 검증 프로필은 **`Qwen/Qwen3.8-27B-FP8`**이며 [모델 설정](ai/configs/qwen38-27b-fp8.json)에 기록되어 있습니다. 실제 연결 서버의 모델은 운영 설정에 따라 달라집니다. 기본 실험 설정과 최근 검증 프로필이 다르므로, 서버 재현 시 사용할 프로필을 명시해야 합니다.

AI는 발화와 평가·정보 공개 후보를 생성하며, **진행 확정·정보 공개·보상·구매·저장은 Unity의 규칙이 담당**합니다. 응답 오류를 임의의 성공 대사나 점수로 대체하지 않습니다. 제작 도구, 프롬프트, 모델·음원 출처와 검증 기록은 [통합 기획서](docs/plan01.md), [AI 진행 기록](ai/progress.md), [음원 제작 명세](tools/audio-production/manifest.json), [BGM 재현 안내](tools/audio-production/bgm-reproduction.md)에 정리했습니다.

다양성과 포용은 인물을 소개하는 문구뿐 아니라 **AI가 반응하는 규칙**에도 반영했습니다. 설정에 없는 성별·국적·가족 이력을 임의로 덧붙이지 않고, 강요된 동의를 충분한 변화의 근거로 평가하지 않도록 프롬프트와 인물별 기준을 작성했습니다. 취업·이직·재결합·발표 참여 같은 특정 결말은 필수 정답으로 두지 않습니다. 이러한 규칙은 제작 의도와 구현 기준이며, 모든 생성 응답의 편향이 제거되었다는 검증 결과를 뜻하지는 않습니다.

## 5. 실행 시 확인 사항

| 현상 | 확인할 내용 |
| --- | --- |
| 연결 설정 오류 / 답변을 받지 못함 | 인터넷, AI 서버 가동 여부, 설정 파일 위치와 `api_url`·`api_key`를 확인합니다. 연결을 복구한 뒤 화면의 재시도 기능을 사용합니다. |
| 불러오기 버튼 비활성화 | 현재 환경에 불러올 수 있는 저장 진행이 없는 상태입니다. 새 게임으로 시작합니다. |
| 상담 종료 후 다음 내담자가 바로 오지 않음 | 평가·저장 완료 후 `환자 내보내기`를 누르고 다시 문을 클릭합니다. 두 점수 모두 70점 이상이어야 다음 내담자가 해금됩니다. |
| 실행 파일을 옮긴 뒤 게임이 열리지 않음 | 실행 파일만 분리하지 말고 `_Data` 폴더와 DLL 등 빌드 폴더 전체를 함께 둡니다. |

현재 버전에는 정식 후일담 사진·크레딧 등 일부 콘텐츠의 **준비 중** 표시가 남아 있습니다. 플레이와 보상·다음 내담자 진행은 이어갈 수 있습니다. 일부 추가 효과음은 제작된 에셋만 있으며 모든 조작에 연결된 것은 아닙니다.

최신 소스의 AI API 0.4.4에는 환자 응답을 최대 60자·한 문단으로 제한하는 기능이 있습니다. 실제 적용에는 해당 서버 버전의 배포가 필요하며, 구 서버·구 저장의 긴 원문은 대화칸 스크롤로 열람합니다.

개발 전용 70/70 스킵은 일반 플레이의 평가 기능과 구분됩니다. Editor에서 Play 전에 `Gamsamo > Development > 70-70 Skip Preview (separate save)`를 켜면 별도 개발 저장으로 진행 흐름을 확인할 수 있습니다. 기본값은 OFF이며 일반 출시 빌드에서는 사용할 수 없습니다.

제출 전에는 **최종 ZIP을 새 폴더에 압축 해제하고 `우리동네상담사.exe` 실행·AI 연결·저장/불러오기를 확인**합니다. 기존 자동 검사와 실제 서버 검증의 범위는 [통합 기획서 17절](docs/plan01.md#work-history)에 기록되어 있습니다.
